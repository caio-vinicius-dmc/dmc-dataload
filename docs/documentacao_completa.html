🔭 1. Visão Geral da Aplicação

O DMC DataLoad é uma plataforma web de orquestração ETL (Extract, Transform, Load) que permite gerenciar rotinas de carga de dados, pipelines visuais e workflows automatizados. A aplicação se conecta a múltiplos bancos de dados (PostgreSQL, MySQL, Oracle, SQL Server, ODBC) e suporta integração com APIs externas.

Principais Capacidades

  • Gerenciamento de Rotinas com execução de SQL multi-bloco
  • Pipeline Builder visual com 3 modos: No-Code, Low-Code e Code
  • Workflow Builder visual com drag-and-drop e nós condicionais
  • Conexão a múltiplos bancos de dados (5 drivers suportados)
  • Integração com APIs externas com polling e detecção de eventos
  • Agendamento via expressões CRON com controle do daemon
  • Histórico unificado de execuções (rotinas + pipelines + workflows)
  • Calendário visual de agendamentos (FullCalendar)
  • Editor SQL com suporte multi-banco
  • Diagrama visual de schemas de banco de dados
  • Dashboard com métricas consolidadas e gráficos
  • Sistema de notificações in-app
  • Gerenciamento de usuários com suporte LDAP

Arquitetura

PadrãoMVC com Front Controller (public/index.php)
BackendPHP 8.2+ com PDO, Composer para dependências
Banco de DadosPostgreSQL (principal) + conexões externas multi-driver

✨ 3. Todas as Funcionalidades

3.1 — Rotinas (Tarefas SQL)

  • CRUD completo (criar, editar, excluir, listar)
  • Editor SQL com blocos de código
  • Execução manual com confirmação detalhada (mostra query que será executada)
  • Execução agendada via expressão CRON
  • Toggle ativar/desativar rotina
  • Estatísticas por rotina (últimas execuções, taxa de sucesso)
  • Registro de logs com duração, registros processados, erros
  • Suporte a múltiplas conexões de banco

3.2 — Pipelines

  • CRUD completo + duplicação + export/import
  • 3 modos de construção: No-Code (visual), Low-Code (híbrido), Code (livre)
  • Pipeline Builder visual com arraste e solte de nós
  • Nós de SQL, HTTP, transformação, filtro, junção, etc.
  • Trigger por CRON, manual ou evento API
  • Versionamento automático
  • Variáveis de pipeline configuráveis
  • Tags para organização
  • Execução com log detalhado por nó
  • Histórico de execuções por pipeline

3.3 — Workflows

  • CRUD completo + duplicação
  • Workflow Builder visual com canvas drag-and-drop
  • 8 tipos de nós: trigger, rotina, condição, delay, notificação, loop, paralelo, fim
  • Conexões com lógica condicional (sempre, sucesso, erro, expressão customizada)
  • Trigger por CRON, manual, ou evento API
  • Execução com rastreamento no nível do nó
  • Versionamento de workflow
  • Estatísticas de workflow
  • Página de execuções com detalhes e cancelamento

3.4 — APIs Externas e Eventos

  • CRUD de APIs externas (URL, método, headers, body)
  • 4 tipos de autenticação: none, bearer, basic, api_key
  • Teste de API com visualização da resposta completa
  • Polling periódico com intervalo configurável
  • Timeout e configurações avançadas
  • Eventos API com JSONPath/XPath para detecção de mudanças
  • Operadores: equals, contains, regex, greater_than, in_array, etc.
  • Captura e armazenamento de valores da API
  • Disparar workflow automaticamente quando evento é detectado

3.5 — Agendamento (Scheduler)

  • Gerenciamento de agendamentos CRON por rotina
  • Controle do daemon scheduler (start/stop/toggle)
  • Status em tempo real do scheduler
  • Logs do scheduler (últimas execuções automáticas)
  • Presets de expressões CRON comuns
  • Validação de expressões CRON

3.6 — Calendário

  • Visualização mensal/semanal/lista de agendamentos
  • Eventos CRON de rotinas e pipelines
  • Execuções passadas de rotinas, pipelines e workflows
  • Filtro no sidebar por rotina/pipeline
  • Cores distintas por tipo de evento
  • Detalhes ao clicar no evento
  • Correção: IDs mistos (pip_X) não causam mais erro SQL (bug crítico corrigido)

3.7 — Histórico Unificado

  • Listagem unificada com UNION ALL (rotinas + pipelines + workflows)
  • Filtro por tipo (rotina/pipeline/workflow)
  • Filtro por status (sucesso/falha/executando/cancelado)
  • Filtro por período (data início e fim)
  • Detalhes de cada execução (blocos, duração, erros)
  • Re-execução direta do histórico
  • Exportação CSV com coluna tipo_execucao
  • Download CSV de resultados individuais

3.8 — Dashboard

  • Cards com métricas: total rotinas, pipelines, workflows, em execução
  • Gráfico de execuções dos últimos 7 dias (sucesso vs falha)
  • Últimas execuções recentes
  • Status do scheduler
  • Métricas consolidadas de todos os tipos

3.9 — Ferramentas de Banco de Dados

  • Editor SQL com syntax highlighting (CodeMirror)
  • Execução de queries em qualquer conexão configurada
  • Navegação por schema, tabelas, views, funções, procedures
  • Lazy-loading de objetos do banco
  • Diagrama visual de schema (tabelas e relacionamentos)
  • Detalhes de estrutura de tabelas (colunas, tipos, constraints)
  • Posições salvas do diagrama

3.10 — Administração

  • CRUD de usuários (criar, editar, excluir)
  • Reset de senha
  • 3 níveis de acesso: admin, user, viewer
  • Flag LDAP por usuário
  • Gerenciamento de drivers de banco de dados
  • Instalação automática de drivers
  • Logs do sistema com filtragem e exportação
  • Configurações gerais da aplicação

3.11 — Notificações

  • Sistema de notificações in-app armazenadas no banco
  • Contagem de não lidas via API
  • Marcar como lida individual e em lote
  • Triggers automáticos em falha de execução (ServicoNotificacao)
  • Notificações por E-mail SMTP (ServicoEmail) — socket puro, sem dependência externa
  • Webhooks de Notificação (ServicoWebhook) — HMAC-SHA256, CRUD completo, teste de disparo
  • Integração automática: falha de execução → e-mail + webhook
  • Integração Slack/Teams/Discord via canais de notificação (ServicoCanalNotificacao)

3.13 — Auditoria

  • Registro automático de todas as ações administrativas
  • Ações rastreadas: login, logout, criar, editar, excluir
  • Entidades: sessão, rotina, pipeline, workflow, empresa, usuário, conexão, configuração
  • Captura: IP, User-Agent, dados antes/depois (JSON diff)
  • Página dedicada com filtros, busca, paginação e exportação CSV
  • Estatísticas em tempo real (total, criações, edições, exclusões, logins)

3.14 — Configurações Avançadas

  • Backend completo para página de configurações (ConfiguracoesController)
  • Grupos: geral, email, ldap, scheduler, seguranca, notificacoes
  • Exportar/Importar configurações (JSON)
  • Teste de e-mail direto da interface
  • Limpeza de dados antigos (logs, rate_limits)
  • 20 configurações padrão pré-carregadas

3.15 — Fila de Execução (Background Queue)

  • Enfileiramento de rotinas, pipelines e workflows
  • Prioridade configurável (1-5)
  • Worker CLI com shutdown graceful e sinais POSIX
  • Retry automático com backoff exponencial (30s, 2m, 8m)
  • Proteção contra duplicatas (pendente/processando)
  • SELECT FOR UPDATE SKIP LOCKED para concorrência
  • Recuperação de itens travados (timeout 30 min)
  • Página admin com estatísticas e cancelamento

3.16 — Canais de Notificação (Slack/Teams/Discord)

  • CRUD de canais com webhook URL
  • 3 tipos suportados: Slack (Block Kit), Teams (MessageCard), Discord (Embed)
  • Filtro por evento: sucesso, falha, início
  • Filtro por tipo de recurso: rotina, pipeline, workflow
  • Teste de disparo direto da interface
  • Integração automática com ServicoNotificacao e ServicoExecucao

3.17 — Backup & Restore

  • 3 tipos: completo, rotinas, configurações
  • Exportação para JSON com metadados (_meta)
  • Download direto do arquivo de backup
  • Restauração por upload com validação e FK ordering
  • Proteção contra path traversal (realpath check)
  • Checksum SHA-256 para integridade
  • Acesso restrito a super_admin

3.12 — Conexões de Banco

  • CRUD de conexões
  • 5 drivers: PostgreSQL, MySQL, Oracle, SQL Server, ODBC
  • Teste de conexão antes de salvar
  • Criptografia de credenciais em repouso
  • Status de drivers instalados
  • Informações de instalação de drivers
