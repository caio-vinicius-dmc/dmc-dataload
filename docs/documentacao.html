Visão Geral

O DMC DataLoad é um sistema completo de orquestração ETL que permite criar e gerenciar pipelines de dados através de uma interface web moderna. O sistema foi desenvolvido para automatizar processos de extração, transformação e carga de dados entre diferentes fontes.

Propósito
  • Automatizar rotinas de processamento de dados SQL
  • Agendar execuções com expressões CRON
  • Centralizar conexões de banco de dados com segurança
  • Monitorar execuções em tempo real
  • Gerar logs e históricos detalhados
  • Exportar resultados em CSV

Funcionalidades
Gestão de Conexões

Cadastro e gerenciamento de múltiplas conexões de banco de dados PostgreSQL com senhas criptografadas.

Editor de Rotinas

Interface visual para criar rotinas ETL com múltiplos blocos SQL (SELECT, INSERT, UPDATE, DELETE).

Agendamento CRON

Agendar execuções automáticas usando expressões CRON com presets pré-definidos.

Execução Manual

Executar rotinas manualmente com feedback em tempo real do progresso e resultados.

Histórico de Execuções

Visualizar histórico completo com status, duração, registros processados e mensagens de erro.

Calendário Visual

Visualização das execuções em formato de calendário com código de cores por status.

SQL Editor

Editor SQL profissional com syntax highlighting, explorador de objetos, autocomplete inteligente e dinâmico (schemas, tabelas, views, colunas baseados no banco conectado), zoom dinâmico e múltiplos atalhos de teclado. Layout configurável em 2 modos: vertical (editor acima, resultados abaixo) ou horizontal (3 colunas: Database Explorer | Editor | Resultados).

Exportação CSV

Exportar resultados de queries SELECT para arquivos CSV automaticamente.

Gestão de Usuários

Administração de usuários com níveis de acesso (admin, operador, visualizador).

Logs do Sistema

Visualização e exportação de logs do sistema com filtros por nível e período.

Dashboard

Painel com métricas em tempo real: execuções, falhas, próximas rotinas e gráficos.

Autenticação Segura

Login com sessão segura e suporte futuro para LDAP/Active Directory.

Instalação
Requisitos
  • PHP 8.2 ou superior
  • PostgreSQL 15 ou superior
  • Composer 2.x
  • Extensões PHP: pdo_pgsql, openssl, mbstring, json
Passo a Passo
# 1. Clone o repositório git clone https://github.com/caio-vinicius-dmc/dmc-dataload.git cd dmc-dataload # 2. Instale as dependências composer install --no-dev # 3. Configure o ambiente cp .env.example .env # 4. Edite o arquivo .env com suas configurações DB_HOST=localhost DB_PORT=5433 DB_DATABASE=db_dmc_dataload DB_USERNAME=postgres DB_PASSWORD=sua_senha ENCRYPTION_KEY=chave_base64_32_bytes # 5. Execute o script SQL inicial psql -U postgres -d db_dmc_dataload -f sql/02-02-2026.sql # 6. Gere a chave de criptografia php scripts/encrypt_password.php # 7. Inicie o servidor php -S localhost:8080 -t public

Fluxo da Aplicação
Fluxo de Execução de Rotina
1
Criação da Rotina

Usuário cria rotina no editor visual com blocos SQL

2
Configuração de Conexão

Associa perfil de conexão (com senha criptografada)

3
Agendamento (Opcional)

Configura expressão CRON para execução automática

4
Execução

Manual ou automática via scheduler worker

5
Processamento

ServicoExecucao processa cada bloco sequencialmente

6
Exportação

Blocos SELECT geram arquivos CSV automaticamente

7
Registro

Log completo salvo em tb_logs_execucao

Segurança
Criptografia AES-256-CBC

Senhas de conexão são criptografadas usando AES-256-CBC com chave de 32 bytes base64.

Sessão Segura

Sessões PHP com configurações de segurança (httponly, samesite, secure em produção).

Autenticação

Middleware de autenticação em todas as rotas protegidas.

Prepared Statements

Todas as queries usam prepared statements para prevenir SQL Injection.

Variáveis de Ambiente

Credenciais armazenadas em .env fora do controle de versão.

Hash de Senhas

Senhas de usuários armazenadas com bcrypt (PASSWORD_DEFAULT).
